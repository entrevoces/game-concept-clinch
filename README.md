# Voice Atelier — an ENTRE VOCES game

Standalone bundle generated by `tools/publish/publish.mjs` from the entrevoces monorepo.
Open `index.html` via any static host (GitHub Pages works). The engine client is vendored
under `engine/`; progress is local-first and syncs to a Progression Engine when configured.
